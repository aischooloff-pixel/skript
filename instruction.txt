ИНСТРУКЦИЯ: ЛИЧНЫЙ ИИ-МЕНЕДЖЕР ДЛЯ TELEGRAM АККАУНТА
===================================================

0) ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ
------------------------
- Скрипт работает от вашего ЛИЧНОГО аккаунта Telegram (через API Telegram).
- Соблюдайте правила Telegram и не используйте скрипт для спама.
- Вы сами отвечаете за безопасность API-ключей и файла с базой знаний.


1) ЧТО ДЕЛАЕТ СКРИПТ
--------------------
- Авторизуется в Telegram через:
  - api_id
  - api_hash
  - номер телефона
  - код подтверждения
  - облачный пароль (если включен 2FA)
- Читает базу знаний из файла baza.txt (любой формат).
- При получении сообщения в ЛС:
  - берет текст сообщения,
  - добавляет контекст истории,
  - отправляет запрос в выбранный LLM-провайдер,
  - отвечает собеседнику от вашего лица.


2) ПОДГОТОВКА TELEGRAM API
--------------------------
1. Откройте https://my.telegram.org
2. Войдите по номеру телефона.
3. Зайдите в раздел API development tools.
4. Создайте приложение (любое имя/short name).
5. Сохраните api_id и api_hash.


3) УСТАНОВКА
------------
1. Установите Python 3.10+.
2. Откройте терминал в папке проекта.
3. (Рекомендуется) Создайте виртуальное окружение:
   - Linux/macOS:
     python3 -m venv .venv
     source .venv/bin/activate
   - Windows (PowerShell):
     py -m venv .venv
     .\.venv\Scripts\Activate.ps1
4. Установите зависимости:
   pip install -r requirements.txt


4) НАСТРОЙКА ФАЙЛОВ
-------------------
В проекте есть 2 шаблона конфигурации:
- app_config.json.example
- provider_config.json.example

Скопируйте их:
- app_config.json.example  -> app_config.json
- provider_config.json.example -> provider_config.json

4.1) app_config.json (Telegram)
--------------------------------
Обязательные поля:
- api_id: ваш Telegram API ID (число)
- api_hash: ваш Telegram API hash
- phone: ваш номер в международном формате, например +79991234567

Дополнительно:
- session_name: имя файла сессии (по умолчанию my_telegram_session)
- max_history_messages: сколько сообщений истории хранить на чат (по умолчанию 20)

Пример:
{
  "api_id": 123456,
  "api_hash": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "phone": "+79991234567",
  "session_name": "my_telegram_session",
  "max_history_messages": 20
}

4.2) provider_config.json (ИИ провайдер)
-----------------------------------------
Поля:
- base_url: базовый URL API провайдера
- endpoint: обычно /chat/completions
- api_key: токен провайдера (если требуется)
- model: имя модели
- temperature: «креативность» (0.0-1.0)
- max_tokens: ограничение длины ответа
- timeout_sec: таймаут запроса

Пример для OpenRouter:
{
  "base_url": "https://openrouter.ai/api/v1",
  "endpoint": "/chat/completions",
  "api_key": "sk-or-...",
  "model": "openai/gpt-4o-mini",
  "temperature": 0.7,
  "max_tokens": 350,
  "timeout_sec": 60
}

4.3) baza.txt (база знаний)
---------------------------
- Заполняется в ЛЮБОМ формате.
- Подходит:
  - обычный текст
  - пункты
  - факты о себе
  - цели/проекты
  - стиль общения
  - что можно/нельзя обещать людям

Пример:
Андрей, 20 лет, живу в Казани.
Занимаюсь фронтендом и учусь на 3 курсе.
Люблю короткие и дружелюбные ответы.
Не даю обещаний по срокам, если не уверен.


5) ВЫБОР ПРОВАЙДЕРА: ВАРИАНТЫ
-----------------------------
Вы можете использовать любой OpenAI-совместимый API.

Популярные варианты:
1. OpenRouter
   - Удобно переключать разные модели через один API.
   - Нужен API-ключ.
2. OpenAI
   - Классический официальный API.
   - Нужен API-ключ и оплата по тарифу.
3. Локальный Ollama (без внешнего токена)
   - Можно запускать модель на своем ПК локально.
   - Тогда base_url обычно: http://127.0.0.1:11434/v1
   - api_key можно оставить пустым.
   - Нужен достаточно мощный компьютер.


6) ЗАПУСК
---------
1. Убедитесь, что настроены:
   - app_config.json
   - provider_config.json
   - baza.txt
2. Запустите:
   python ai_manager.py
3. При первом запуске:
   - введите код из Telegram
   - если включен 2FA, введите облачный пароль
4. После входа скрипт начнет обрабатывать входящие ЛС.


7) УПРАВЛЕНИЕ И ЛОГИКА РАБОТЫ
------------------------------
- Скрипт отвечает только на входящие личные сообщения (не в группах).
- Ответы формируются ОТ ВАШЕГО ЛИЦА.
- Скрипт не пишет "я бот" или "я ассистент".
- Контекст прошлых сообщений хранится в памяти процесса.
  После перезапуска контекст обнуляется.


8) ТИПИЧНЫЕ ОШИБКИ И РЕШЕНИЯ
----------------------------
1. "Не найден файл app_config.json / provider_config.json"
   - Вы не скопировали .example файлы.

2. "Файл baza.txt пуст"
   - Добавьте информацию о себе в baza.txt.

3. Ошибка авторизации Telegram
   - Проверьте api_id/api_hash/номер.
   - Убедитесь, что код введен правильно и не просрочен.

4. Ошибка модели (HTTP 401/403)
   - Неверный API-ключ или недостаточно прав у провайдера.

5. Ошибка модели (HTTP 429)
   - Лимиты провайдера, подождите или смените модель/тариф.

6. Ошибка формата ответа модели
   - Провайдер может быть не полностью OpenAI-совместим.
   - Проверьте endpoint и формат в provider_config.json.


9) ВОПРОС "МОЖНО ЛИ БЕСПЛАТНУЮ МОДЕЛЬ НАВСЕГДА БЕЗ ТОКЕНА?"
------------------------------------------------------------
Коротко: гарантировать "бесплатно и навсегда" для облачных API нельзя.

Реальный вариант без внешнего токена:
- использовать локальную модель через Ollama (или аналог),
- тогда вы не платите провайдеру за токены,
- но платите ресурсами своего компьютера (CPU/GPU/электричество),
- качество и скорость зависят от железа.


10) ПОЛЕЗНЫЕ СОВЕТЫ
-------------------
- Храните API-ключи в безопасном месте.
- Регулярно обновляйте baza.txt — ответы станут точнее.
- Добавьте в baza.txt блок "как я общаюсь" (тон, длина ответов, табу-темы).
